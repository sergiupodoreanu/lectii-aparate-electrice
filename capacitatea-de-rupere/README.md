# Capacitatea de rupere a aparatelor de protecție — fișă de curs

Material didactic pentru Școala de maiștri electricieni, Liceul Tehnologic „Grigore C. Moisil” Buzău. Autor: Prof. Sergiu Podoreanu.

Conținut: definiție și regula I7 4.3.5.1; Icn / Icu / Ics / Icm / Icw / Inc; citirea marcajelor; determinarea Isc prezumat (NTE 006, formula Schneider, metoda impedanțelor); exemplu atelier 250 kVA; exemplu rezidențial; filiație; verificarea cablului (I7 4.3.5.2); 4,5 vs 6 vs 10 kA; tabel de aparate Schneider / ABB / Hager / Schrack cu linkuri către fișele tehnice; test (10 întrebări).

Citatele din Normativul I7-2011 sunt reproduse exact, în casetele albastre. Desenele (fig. 1–6) sunt SVG originale.
