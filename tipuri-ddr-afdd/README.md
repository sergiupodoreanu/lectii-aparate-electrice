# Tipurile de DDR (AC, A, F, B) și AFDD

Fișă de curs pentru Școala de maiștri electricieni — Liceul Tehnologic „Grigore C. Moisil” Buzău.
Autor: Prof. Sergiu Podoreanu.

Conținut:
- tabel comparativ DDR tip AC / A / F / B — curent de defect sesizat, simbol, aplicații, consumatori;
- articolele din Normativul I7-2011 (Ordinul 2741/2011, modificat prin Ordinul 959/2023) care tratează DDR: 4.1.5.2.1–4.1.5.2.8, 4.1.4.1.11, 4.2.2.8, 7.9.11–7.9.12, 7.11.7–7.11.8, 4.1.5.8, 4.2.2.10–4.2.2.12;
- AFDD (SR EN 62606): tipurile de arc, semnătura în forma de undă, lanțul de detecție, timpii de întrerupere, poziția în tablou;
- fotografii de pe Wikimedia Commons, cu autor și licență sub fiecare imagine.
