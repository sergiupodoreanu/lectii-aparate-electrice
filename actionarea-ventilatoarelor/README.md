# Acționarea ventilatoarelor cu convertizor de frecvență

Lecție pentru Școala de maiștri electricieni (Liceul Tehnologic „Grigore C. Moisil” Buzău).

- `index.html` — lecția (recapitulare convertizor: n₁ = 60·f₁/p, structură, legea U₁/f₁, comandă scalară/vectorială; dicționar de termeni; ventilatorul și curbele; legile de similitudine; metode de reglare; motorul; alegerea pas cu pas; funcțiile convertizorului; exemple din grajduri de porci/păsări/vaci și din industrie; instalare; verificări și măsurători; punere în funcțiune; fișe de parametrizare Danfoss FC 51/FC 102, Siemens V20/G120, Schneider ATV12/320/212, ABB ACH580, Ziehl-Abegg Fcontrol; cazuri rezolvate; test fără răspunsuri).
- `svg/` — 18 scheme SVG editabile în Inkscape (straturi „Aparate” / „Conductoare” / „Text”), generate de `scheme_svg.py` + `svglib.py`.
- `img/` — fotografii Wikimedia Commons; autorul și licența fiecăreia sunt în `img/credits.json` și sub fiecare imagine în lecție.

Surse: documentația producătorilor (Danfoss, Siemens, ABB, Schneider Electric, Ziehl-Abegg, ebm-papst, Helios, Vostermans, SKOV), DLG, DIN 18910, TierSchNutztV, LfL Bayern, Chambres d'agriculture — linkuri în bibliografia lecției.
