# Circuite de curent alternativ

Patru lecții pentru Școala de maiștri electricieni (Moisil, Buzău), scrise pe înțelesul tuturor (fără numere complexe, doar triunghiul dreptunghic):

1. Curentul alternativ sinusoidal — valoare instantanee, maximă, efectivă, perioadă, frecvență, defazaj, fazori
2. Rezistorul, bobina și condensatorul în c.a. — reactanțe, impedanță, circuitul RL, rezonanța
3. Puterile în c.a. — activă, reactivă, aparentă, triunghiul puterilor, cos φ, compensarea
4. Rețele trifazate — tensiune de fază / de linie, stea, triunghi, puteri, neutrul întrerupt, plăcuța motorului

Terminologia urmează manualele românești; termenii germani și francezi sunt dați în paranteze. Sursele sunt listate la sfârșitul paginii.

- `index.html` — lecția (cu gate de parolă)
- `img/` — fotografii de pe Wikimedia Commons; autorul și licența sunt indicate sub fiecare fotografie
- `svg/` — cele 15 scheme, ca fișiere SVG editabile (Inkscape)
- `scheme_svg.py` — scriptul Python care generează schemele

Răspunsurile testelor nu sunt publicate.
