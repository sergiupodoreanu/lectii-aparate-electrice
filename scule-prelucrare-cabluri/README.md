# Scule și dispozitive pentru prelucrarea cablurilor

Lecție pentru Școala de maiștri electricieni (Moisil, Buzău): debitare, îndepărtarea mantalei, dezizolare, tuburi terminale (DIN 46228-1/-4), sertizarea tuburilor și a papucilor, scule izolate VDE (SR EN 60900), cabluri de date, greșeli frecvente, exemple numerice, fișă de atelier și test. Terminologia germană este dată pentru cataloagele producătorilor (Knipex, Weidmüller, Wago, Klauke, Jokari, Wiha).

Răspunsurile testului nu sunt publicate.
